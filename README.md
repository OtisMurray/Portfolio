# Portfolio
Here is a collection of my major projects developed through my college career.

## Link to collaborative PSU Hackathon Fall 2024 Project that won the best use of MongoDB Atlas
https://github.com/rmedcraft/Daily-Journal

Description: Flags for warning signs of various mental illnesses using a custom AI model based on journal entries entered by the user

## Skills learned

Data preprocessing: missing values, scaling, encoding, and feature engineering

Dimensionality reduction: PCA for variance retention, t-SNE for visualization

Predictive modeling: XGBoost regression & classification, Gaussian Mixture Models

Model tuning: cross-validation and hyperparameter optimization

Visualization: scatterplots, cluster probabilities, and feature interpretation

Directory Management: structured raw, interim, and processed datasets, allowing for reproducibility

Analysis of results: Accurately determining results and explaining what they mean in understandable terms

Programming tools: R (dplyr, caret, ggplot2, xgboost, ClusterR), Python (embeddings, libraries like Pandas and Matplotlib), and SQL (RDBMS)
