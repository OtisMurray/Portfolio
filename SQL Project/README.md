Worked as a developer in a team that designed and implemented a relational database management system to assess volunteers, tasks, assignments, packages, and items for the United Helpers Organization. During this project I contributed directly to SQL table creation, data integrity enforcement, and queries to monitor volunteer assignments and task completion. It was a fun experience as we were all being evaluated on our ability to communicate in a more professional environment and keep track of our own tasks and group progress. We then were able to ready our work for web access through the use of PostgREST API support.
